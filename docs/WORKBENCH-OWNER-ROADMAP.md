# Brickwright workbench requests

This is the durable backlog for the retro machines, circuit examples, and workbench UI. Keep each item here when work moves between agents, repositories, or builds. Mark an item verified with the commit and the exact test or observed workflow. A working boot, a rendered widget, and a passing program each provide different evidence.

## Current priorities

1. Make the machine paths predictable. Run current Code from the green flag, keep guest input and output in Controller, and keep debugger inspection independent of the selected right-pane view.

Apply the same ordering to saved images, lessons, downloads, and compatible circuit examples. Preserve search and the single-machine filter.

4. Keep filling the functional circuit coverage gap. Use the CLI and report startup and lesson behavior independently.

### Circuit audit denominator

The current Examples index has 807 entries. Of these, 780 have a circuit file or a named board variant. The other 27 are program entries with no bench in this audit. The CLI counts a default circuit once unless a named variant already points to it, then checks every named device variant. That produces 722 default-circuit rows and 1,249 device-specific rows, for 1,971 audit cases. A red circuit diagnostic can be the expected outcome of a lesson that deliberately ships a wiring fault.

The follow-up exercised all 501 previously unverified cases across 195 lesson IDs. Of these, 230 passed and 271 failed. A deeper screen test also found that the previously passing default voltmeter drops its unit at midrange. The net result is **1,699 passing and 272 failing variants**, with a verdict for every variant. A pass covers the assertion recorded for that variant. The PRECHIN A2 learning board is an authored wiring reference. Its pass checks topology and shared nets, with no bundled program to execute. The subagent exercised 363 variants, including the previously passing voltmeter and the 13 remaining discrete-computer lessons. [Per-variant verdicts](receipts/2026-11-26-circuit-functional-follow-up.tsv)

The display repair cleared another 59 failures and rechecked the previously passing bargraph variant. The voltmeter and ammeter now show measured values with units across all 18 variants. - **Calibration and documentation.** All seven servo variants reproduce the full sweep at 0.5–2.5 ms. Two compiled 8051 firmware variants reproduced that range in the CPU simulator.
